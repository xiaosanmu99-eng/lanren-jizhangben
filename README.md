# 懒人记账本

肖三木的私人支出账本。手机宽度的网页，用来记食堂和其他开销。它不是微信小程序，也不借用微信的标志或登录。

账记在服务器的 Postgres 里，金额用整数分。要先登录，未登录的接口不返回任何账目。

## 现在还没接上的事

- 没有公开发布的网址。这台预览只在当前服务上，微信打不开。
- 没有云同步开关。浏览器 `localStorage` 不保存账。
- 聊天记账没有接上。`POST /api/ingest` 只有在服务器设置了 `LEDGER_INGEST_TOKEN` 之后才接受请求，而且这个环境默认不配这个令牌。
- 每周日 20:00（Asia/Shanghai）的自动复盘没有定时任务，不会自己跑。打开「本周」可以随时看，并导出一张用真实账目画的 PNG。

## 本地运行

需要 Node.js 和 Postgres。

```bash
npm install
cp .env.example .env.local
# 把 DATABASE_URL 指到你自己的库，并换掉 LEDGER_SETUP_TOKEN
npm run dev
```

开发服务监听 `http://127.0.0.1:43123`。

第一次打开时，在页面里输入配置口令和你自己的登录口令。配置口令只放在表单里，不放在网址里。建好之后，平时只用登录口令。

## 账怎么存

| 位置 | 实际含义 |
| --- | --- |
| 本机预览 | `DATABASE_URL` 指向这台机器的 Postgres。数据在数据库里，不在浏览器里。预览进程或这台机器没了，手机也到不了这本账。 |
| 发布之后 | 同一个程序读取托管环境注入的 `DATABASE_URL`。还要单独设置 `LEDGER_SETUP_TOKEN`。发布和密钥都要你确认，这个仓库里没有生产口令。 |

分类是：食堂、其他餐饮、交通、购物、其他。日期按 Asia/Shanghai 的日历日。退款存成负的整数分。

一句话记账是确定性规则。金额、分类或日期看不清时，页面会先请你确认，不会自动补一笔。小数超过两位直接拒绝，不四舍五入。

导入 JSON 时，相同编号会跳过；日期、金额、分类、商户都相同会先警告。

## 将来的记账入口

助手以后可以这样写入，现在没有助手在调用：

```http
POST /api/ingest
Authorization: Bearer <LEDGER_INGEST_TOKEN>
Content-Type: application/json

{"text":"食堂 18.5","externalId":"message-id"}
```

句子明确时返回 `201`。含糊时返回 `409`，不写入。同一个 `externalId` 再发一次会返回已有的那笔，不会记第二遍。令牌至少 16 位，只放在服务器密钥里。

## 测试

测试覆盖整数分、退款、句子解析、按周汇总、未登录拒绝，以及关掉数据库连接后记录仍在。

## 发布

代码放在 Origin 仓库里。Origin 本身只存代码，不运行这个网站。Cursor 的应用发布可以提供 HTTPS 和 Postgres，但要你在发布托盘里确认网址；公开之前还会做安全检查。这一步没有代你完成，也没有新的付费托管。

要在微信里当普通链接打开，页面必须是微信浏览器能直接打开的 HTTPS，而不能先过一层 Cursor 登录。账目仍然只在这个应用自己的登录之后才读得到。微信内置浏览器这次没有实测。
